​📌 Overview
​Screen Lock Security App is a lightweight Python desktop application designed to secure your environment. It features a sleek digital keypad interface. If an unauthorized user inputs the wrong password, the system instantly triggers the webcam, captures a photo of the intruder, and saves it locally.
​✨ Features
​🔢 Digital Keypad UI: Easy-to-use numeric interface built with Tkinter.
​🔒 Secure Authentication: Passcode validation to grant access.
​📸 Intruder Detection: Automatically takes a photo (look.png) using OpenCV on failed attempts.
​🎨 Clean & Semi-Transparent GUI: Modern window styling with custom opacity (alpha = 0.8).
​⚡ Executable Ready: Convertible to a standalone .exe for Windows.
